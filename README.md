# Ozon E-Cup 2026: прогноз 30-дневного GMV пользователей

Репозиторий содержит итоговое решение задачи регрессионного прогнозирования, представленной на соревновании Ozon E-Cup 2026. Работа выполнена индивидуально и заняла 86-е место среди 316 команд. Всего в соревновании участвовали 617 человек.

Задача состояла в том, чтобы для каждого из 250 000 пользователей оценить суммарную стоимость заказов за следующие 30 дней. Прогнозируемый период охватывает даты с 14 февраля по 15 марта 2026 года. Под GMV здесь понимается общая стоимость оформленных заказов пользователя в Поиске и Каталоге Ozon.

Исходные данные представляют собой разреженную историю ежедневной активности с 1 января 2025 года по 13 февраля 2026 года. В ней содержатся сведения об использовании Поиска и Каталога, добавлениях товаров в корзину, оформленных заказах, количестве товаров и связанных с ними денежных суммах. Для многих пользователей целевое значение равно нулю, а положительные суммы распределены крайне неравномерно. Поэтому модели обучаются предсказывать логарифмированную величину `log(1 + GMV)`, которая соответствует используемой в соревновании мере качества RMSLE.

Итоговое решение построено на моделях градиентного бустинга CatBoost. История пользователя преобразуется в числовое описание его поведения к выбранной опорной дате. В него входят показатели недавней активности, покупательской воронки, аналогичного календарного периода прошлого года, годовой истории, периодичности заказов и денежного поведения. Наиболее полная модель использует 428 признаков.

Прогноз формируется в несколько этапов. Сначала две контрольные модели оценивают будущий GMV по общей активности пользователя и периодичности его заказов. Их результаты объединяются в логарифмической шкале. Затем строится отдельная денежная модель, которая подробнее учитывает суммы предыдущих покупок, средний чек, давность последних заказов, изменение денежной активности и предполагаемое продолжение покупательского ритма. Итоговая оценка объединяет контрольный и денежный прогнозы.

Для пользователей, у которых за доступную историю не было ни одного дня с заказом, применяется отдельное защитное правило. Денежная поправка для них отключается, после чего сохраняется контрольный прогноз. Пользователь при этом не получает нулевое значение автоматически, поскольку поисковая активность, работа с каталогом и добавления товаров в корзину всё ещё могут указывать на будущую покупку.

В репозитории сохранён полный путь воспроизведения результата: подготовка обучающих срезов, расчёт признаков, обучение моделей, локальная проверка гипотез, смешивание прогнозов и формирование итогового файла для отправки в соревнование.

Подробное описание исследования, математической постановки задачи, устройства обучающей выборки, всех 428 признаков, процедуры проверки и итогового алгоритма приведено в документе [README_Theory](README_Theory.md). В нём также разобраны формулы расчёта признаков, параметры моделей, полученные изменения RMSLE, ограничения проведённой проверки и назначение основных файлов проекта.

Готовый файл: `submissions/submission_monetary_cadence_inactive_guard.csv`.

## Состав решения

Конвейерно состоит из трёх уровней:

1. базовые, годовые и ритмические признаки;
2. CatBoost с признаками денежного ритма и его логарифмическая смесь с контрольным прогнозом;
3. защитное правило: для пользователей без активных дней заказов используется только контрольный прогноз.

Подробное теоретическое описание будет вынесено в `README_Theory.md`.
