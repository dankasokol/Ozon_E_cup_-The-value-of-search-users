# Ozon GMV — прогноз 30-дневного GMV

Проект организован так, чтобы исследования в ноутбуках не дублировали производственный код.

## Структура

- `data/` — исходный датасет `train.parquet`; не изменяется кодом проекта.
- `notebooks/` — исследовательские и обучающие ноутбуки в порядке работы.
- `src/` — общие функции загрузки, построения признаков, валидации, обучения и оценки.
- `artifacts/` — промежуточные срезы, метрики, важности признаков и обученные модели.
- `submissions/` — готовые CSV для отправки в соревнование.

Логика первого CatBoost-решения вынесена из `04_first_catboost_ltv.ipynb` в `src/`. Ноутбук теперь только задаёт последовательность эксперимента, а общие функции используются из одного места.

Каждый завершённый эксперимент оформляется отдельным нумерованным ноутбуком. Второй вариант решения с расширенными временными признаками находится в `notebooks/06_catboost_v2.ipynb`.
